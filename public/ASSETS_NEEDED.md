# Required Assets

The following assets need to be created for proper branding and SEO:

## Favicons
- `favicon.ico` - Standard favicon
- `favicon-16x16.png` - 16x16 favicon
- `favicon-32x32.png` - 32x32 favicon
- `apple-touch-icon.png` - 180x180 Apple touch icon
- `android-chrome-192x192.png` - Android icon
- `android-chrome-512x512.png` - Android large icon

## Open Graph Image
- `og-image.png` - 1200x630 pixels
  - Show OhMyReads logo and tagline
  - Light mode: Warm cream background (#FFFBF5), brown text (#8B4513)
  - Include: "Track Your Reading Journey"

## Logo
- `logo.png` - Main logo for JSON-LD schema

## Recommended Tools
- Use https://realfavicongenerator.net/ to generate favicon set
- Use Figma or Canva to create og-image.png
